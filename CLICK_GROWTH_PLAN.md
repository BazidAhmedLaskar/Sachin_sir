# Organic click growth plan

This is a 90-day plan for the independent Sachin Sir Study Notes website. It is designed to increase *qualified* visits from students, not to guarantee rankings, AdSense approval or a specific number of clicks. Prioritise accuracy and useful explanations over publishing lots of similar pages.

## 1. Establish a baseline (week 1)

1. Deploy the site on its final HTTPS domain. If it is not `sachinsir.netlify.app`, update every canonical URL, Open Graph URL, structured-data URL, `robots.txt` and sitemap URL. Check `/ads.txt` separately.
2. Verify the domain in Google Search Console, submit `/sitemap.xml`, and use URL Inspection to check the home page and guide directory. Verify that pages return HTTP 200 and that neither robots rules nor noindex prevent indexing. Indexing is not guaranteed.
3. In Search Console, record the last 28 days of **organic web clicks, impressions, CTR and average position**, both for the whole site and by page/query/device/country. Export this as a dated baseline. The site has no analytics installed; if additional analytics are added, update the privacy policy and implement any legally required consent first.
4. Test the contact form on the live host, review the site on mobile, and check PageSpeed Insights / Core Web Vitals for the home page and a guide. The images are compressed, but measure the actual deployment rather than assuming performance.
5. Confirm permission to use a standalone portrait if one is supplied. The current homepage links a YouTube-hosted lecture thumbnail to the original video; it is not an ownership or image licence. Replace it with a properly licensed or owner-supplied photo when available.

## 2. Match useful pages to search intent

| Intent / example query ideas (not volume estimates) | Destination | Action |
| --- | --- | --- |
| Sachin Jakhar / Sachin Sir maths | Home | Keep the independent profile factual, cite primary sources and check current faculty and course details. Do not guess qualifications or rank. |
| How to make a JEE maths study plan | `/jee-maths-study-plan.html` | Add an example weekly schedule and questions students actually ask. |
| How to solve JEE maths questions | `/jee-maths-problem-solving.html` | Add explained examples and links to the topic guides. |
| JEE maths revision / error log | `/jee-maths-revision.html` | Add a copyable error-log example and a realistic review routine. |
| Quadratic equations JEE basics | `/quadratic-equations-guide.html` | Add varied worked questions with solutions and check the maths. |
| Limits and derivatives basics | `/limits-and-derivatives-guide.html` | Add a piecewise limit example and prerequisite links. |

Use Search Console queries to learn the actual language students use. A query is a hypothesis, not a promise of traffic. Avoid making near-duplicate pages for every keyword, inserting unsupported claims, or promising ranks/results.

## 3. Eight-week editorial calendar (weeks 2–9)

- **Week 2:** Improve the existing study-plan guide with a sample week for a student balancing school and JEE. Add explicit assumptions and alternatives for different schedules.
- **Week 3:** Publish a functions and domain guide with worked examples and practice answers; link it to limits and derivatives.
- **Week 4:** Expand the quadratic guide with inequalities and restrictions, checking every example independently.
- **Week 5:** Publish a coordinate geometry foundations guide (slope, distance and line equations), with diagrams and answers.
- **Week 6:** Expand the revision guide with a filled-in error log and a post-mock-test review checklist.
- **Week 7:** Publish a trigonometry identities guide with a derivation, domain cautions and practice questions.
- **Week 8:** Improve the problem-solving guide with a mixed-topic worked example. Link each guide to a logical next step, and add every new public page to the sitemap and guide directory.
- **Week 9:** Refresh the educator profile and verify all time-sensitive references with official sources. Review the highest-impression existing pages before creating more.

For every article: answer a specific question early; provide original worked examples with checked solutions; add a concise, accurate title and description; add useful internal links, descriptive image alt text and relevant `Article`/breadcrumb schema that matches visible content. Disclose sponsorships and do not imply affiliation. Use the latest official exam syllabus when discussing the exam, and do not invent chapter weightages.

## 4. Improve click-through without clickbait (weeks 4–12)

Every two weeks, use Search Console to identify pages with meaningful impressions but comparatively weak CTR. Compare each page only with similar query intent and position: position and query mix strongly affect CTR. Choose one or two pages, record the current title/description and preceding 28-day metrics, then write a clearer title that names the topic and benefit. Make one change at a time and review after at least 28 days, accounting for seasonality, position shifts and low volume. A snippet can be rewritten by Google, and structured data does not guarantee rich results.

## 5. Earn relevant discovery (ongoing)

- Share a helpful worked example or revision checklist in relevant student communities **where rules permit**; link to the full guide only when it adds value. Do not spam comments or buy links.
- Ask teachers and student communities for corrections and topic suggestions. Seek legitimate editorial mentions or collaborations, without claiming endorsement from Sachin Jakhar or PW.
- Offer existing readers a clear next guide at the end of each article. Measure which pages get impressions and clicks before prioritising new work. Do not use intrusive ads or deceptive download buttons.

## 6. Weekly dashboard and decision rules (weeks 1–12)

Record date, organic clicks, impressions, CTR, average position, top five pages, top queries, indexing issues and mobile/desktop split. Compare rolling 28-day periods and the same exam-season period year over year once data exists. Investigate drops by page and query before drawing conclusions. Prioritise: (1) broken or unindexed important pages, (2) factual errors, (3) high-impression pages needing clearer answers, and (4) new topics supported by real questions. If impressions grow but clicks do not, test titles carefully; if neither grows, improve relevance and distribution rather than repeating keywords.

Keep the privacy policy, AdSense configuration, consent management and contact details aligned with actual deployment. Google's policies and final approval decisions apply independently of this plan.
