# Sachin Sir Study Notes

A static, independent profile and JEE mathematics study site. Deploy the repository root as the publish directory; no build command is required.

## Before applying for AdSense

- The site uses `https://sachinsir.netlify.app` as its canonical domain. If the live domain is different, update canonical and Open Graph URLs in the HTML, `robots.txt`, and `sitemap.xml` to the actual public HTTPS domain.
- Deploy and check that `/ads.txt` is publicly reachable and contains the publisher ID shown in your AdSense account. The home page includes the AdSense verification script for that publisher; it does not create manual ad units. Configure placements in AdSense only when appropriate.
- The original profile, including education and rank claims, has been restored for continuity. Some published accounts conflict with these details; verify the claims against reliable primary sources and update them as needed. Batch details, faculty assignments and exam information can change.
- The home page links a YouTube-hosted lecture thumbnail to its original video. Obtain permission for any standalone portrait before uploading it; see `CLICK_GROWTH_PLAN.md` for the growth plan.
- The contact form uses Netlify Forms. Enable form detection in the Netlify site's Forms settings, redeploy, and submit a test message to confirm delivery. If hosting elsewhere, replace the form with a working contact method and update the privacy policy.
- Review the privacy policy and terms against the site's actual operator, data practices and applicable law. Before serving ads where consent is required, configure a Google-certified consent management platform and appropriate consent settings, including for visitors in the EEA, UK and Switzerland. The policy alone is not a consent mechanism.
- Submit the deployed sitemap in Search Console and use the AdSense dashboard to complete site ownership and review steps. These changes do not guarantee approval; Google makes the final decision.
